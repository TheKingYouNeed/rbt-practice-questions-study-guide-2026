# RBT practice question difficulty calibration lab

Original browser-only educational tool published by Dahmani Limited.

Run locally:

```powershell
npx deno run --allow-net main.ts
```

The tool uses five transparent ratings to help authors and learners compare the
study demand of original RBT practice questions. It does not accept or reproduce
secure exam content, provide clinical advice, estimate psychometric difficulty,
or predict exam outcomes.

Production canonical:

`https://rbt-difficulty-calibration.dahmani-limited.deno.net/`
