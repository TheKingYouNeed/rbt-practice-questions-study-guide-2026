Breadth before score

A mixed set is useful only if you know what it samples

A short practice session can feel comprehensive while quietly repeating the same familiar topic. The blueprint coverage planner makes the sampling decision visible. Enter a set size, review a proportional starting allocation, and then label the actual task statements represented by your selected questions.

Direct answer A blueprint coverage plan distributes a mixed practice set across the six current RBT domains, then records which task statements were actually sampled. It supports breadth and review planning; it does not predict an individual examination or convert a small question set into an official mock exam.

The Behavior Analyst Certification Board RBT Test Content Outline (3rd edition) describes 75 scored questions across 43 tasks in 6 domains, plus 10 unscored pilot questions on the examination. The calculator below scales only the 75 scored-question distribution to a chosen study-set size and uses a largest-remainder allocation so the whole-number total stays exact.

Do more than allocate

A four-step coverage-review method

1

Generate the starting mix

Use the calculator to prevent one domain from dominating a short session by accident. Treat the numbers as an allocation prompt, not a prediction.

2

Label the actual task

After selecting each question, record the specific current outline task it most directly samples. Domain labels alone are too broad to prove meaningful coverage.

3

Audit reasoning, not just score

For misses and uncertain correct answers, write the decisive fact, the nearest distractor difference, and the rule you can transfer to a new scenario.

4

Rotate uncovered tasks

Use the next session to sample tasks absent from the current set. Breadth grows across repeated sessions even when each individual set remains short.

Planning examples

How to interpret the suggested allocation

A 12-question set

The proportional mix must use whole questions, so small domains may receive one question while larger domains receive two or three. That does not make the set a miniature official exam; it simply makes the sampling choice visible.

A 24-question set

A medium set can represent all six domains while leaving room to rotate specific task statements across sessions. Compare the planned counts with what your source library can actually provide.

A targeted repair set

After identifying a weakness, you may intentionally override proportional coverage for a focused session. Label the session “targeted,” then return to mixed coverage later so one topic does not crowd out the rest.

Frequently asked questions

Using the coverage planner

Does the calculator create an official RBT mock exam?

No. It scales the current scored-domain distribution to a chosen study-set size. It does not validate question quality, guarantee task-level coverage, reproduce secure content, or predict a real examination form. Record actual task statements and use official BACB sources.

Why do the suggested counts sometimes change by one?

Question counts must be whole numbers. The calculator first computes each exact proportional share, assigns the whole-number floors, and then gives remaining questions to the largest fractional remainders until the requested total is reached.

Should every short session cover all six domains?

Not necessarily. Very focused repair sessions can intentionally emphasize one domain or task. Label them clearly and use a separate mixed-session plan across the week so targeted practice does not become accidental neglect of other areas.

Can I use third-party question tags as proof of coverage?

Treat tags as a starting point. Compare each item with the current official task statements and review the rationale. A publisher’s domain label may be broad, outdated, or imperfect, so maintain your own task-level coverage record.
