RBT Practice Questions: Prompt-to-Evidence Mapping Lab

A practice question can feel difficult because its wording, evidence, and answer choices pull attention in different directions. This lab gives you a repeatable way to map the prompt to the smallest conclusion the stated evidence actually supports.

Scope: All examples below are fictional and written for independent study. They are not clinical instructions, secure examination content, a substitute for required training or supervision, or a promise of any examination result.

The five-field evidence map

Before judging an option, translate the item into five fields. The goal is not to invent a missing fact. It is to make the question's stated limits visible.

1. Command
2. Observable cue
3. Source or domain
4. Minimum conclusion
5. Boundary check
What must the answer do?
Which stated fact changes the decision?
Which official topic or defined concept governs it?
What is the narrowest claim the evidence supports?
What would require more information, authority, or supervision?

A useful map is short enough to write in one minute. If your fourth field is longer than the question stem, you may be adding assumptions instead of reducing them.

Six command words and their evidence burden

Command 01

Identify

Match a stated feature to the best-fitting defined term. Evidence burden: one or more observable features that distinguish the term from nearby alternatives.

Command 02

Calculate

Extract the correct numerator, denominator, unit, and observation window before computing. Evidence burden: every number must come from the stem.

Command 03

Select

Choose the option that satisfies all stated constraints, not merely the option that sounds familiar. Evidence burden: each constraint needs a direct match.

Command 04

Distinguish

Name the feature that separates two plausible concepts. Evidence burden: a contrast, not a general definition of only one choice.

Command 05

Document or report

Prefer observable, objective, relevant information over interpretation. Evidence burden: wording that a second reader could evaluate without guessing intent.

Command 06

Seek direction

Recognize when the stated situation exceeds the information or role boundary in the item. Evidence burden: a clear gap, conflict, or instruction-sensitive condition.

Interactive mapping prompt

Choose the item's command, then write only the evidence explicitly stated in your fictional practice question. The lab returns a compact review frame; it does not decide a real-world clinical action.

Your review frame will appear here.

Keep it factual: command, cue, source, minimum conclusion, boundary.

Four-pass review routine

Pass A

Underline the command

Restate the task in a few words: “calculate a rate,” “distinguish two definitions,” or “choose the objective note.” Do not compare options yet.

Pass B

Box the constraint

Find the fact that makes a tempting option fail: the unit, time window, role boundary, requested measure, or stated instruction.

Pass C

Write the minimum rule

Use a short if-then statement. Example: “If the item requests rate, both the response count and observation time must be represented.”

Pass D

Audit every option

Label each choice supported, contradicted, or unsupported. “Unsupported” matters: an option can sound reasonable but still require facts absent from the stem.

Three fictional worked drills

Drill 1: keep units visible

Prompt pattern: A fictional learner produces 18 responses during a nine-minute observation. The question asks for response rate per minute.

Map: Command = calculate. Cue = 18 responses and nine minutes. Source = measurement vocabulary. Minimum conclusion = divide the stated count by the stated time and preserve “per minute” as the unit. Boundary = do not infer anything about quality, cause, or future performance from this calculation alone.

Drill 2: distinguish description from interpretation

Prompt pattern: Four fictional notes describe the same event, but only one uses observable wording without assigning an internal state.

Map: Command = select. Cue = observable wording is explicitly requested. Source = documentation and reporting. Minimum conclusion = prefer the option that describes what was seen or heard. Boundary = do not add a motive, diagnosis, or unstated causal explanation.

Drill 3: notice the information gap

Prompt pattern: A fictional item describes an unexpected situation while leaving out the relevant instruction. One answer proposes independently changing a procedure; another recognizes the missing direction.

Map: Command = select. Cue = the instruction-sensitive fact is absent. Source = ethics, supervision, and role boundaries. Minimum conclusion = the evidence does not support inventing a new procedure. Boundary = study the role-safe response described by the official source and the question's stated conditions; this exercise does not prescribe action in a real case.

Self-audit before checking the rationale

  1. Can I quote the command word or task phrase?
  2. Did I use only facts that appear in the stem?
  3. Did I preserve units, time windows, and requested measurement dimensions?
  4. Can I state why the strongest distractor fails one specific constraint?
  5. Did I confuse “possibly true” with “supported by this item”?
  6. Did I avoid assuming authority, instructions, or client details that were not given?
  7. Can I connect the rule to a current official source rather than answer memory?
  8. Can I create one new fictional example where the same rule produces a different-looking answer?

That final transfer step is important. If you can apply the rule only to the item you just saw, you may have memorized the surface wording instead of learning the decision boundary.

Use the map to classify distractors

A wrong option is more useful when you can explain its mechanism. After answering, assign the strongest distractor to one of these four categories. The label should describe why the option fails this item—not whether the statement could ever be true in another context.

Distractor A

Right topic, wrong command

The option belongs to the general subject but performs a different task. A definition may be accurate while failing a prompt that asks for a calculation, contrast, or objective note. Rewrite the command in the margin, then test the option against that verb.

Distractor B

Right rule, wrong condition

The option uses a familiar rule but ignores the condition that activates it. Look for the time window, unit, observation feature, stated instruction, or role boundary that the option fails to represent. This is often the most attractive distractor.

Distractor C

Plausible, but unsupported

The choice may sound sensible only because the reader supplies a fact that the stem never gives. Place a question mark beside every inferred motive, history, preference, cause, or instruction. If the answer needs one of those additions, the evidence map is incomplete.

Distractor D

Overbroad conclusion

The option starts from a stated fact and then claims more than that fact establishes. Reduce the sentence until every part is directly supported. The smaller conclusion is usually easier to defend and easier to transfer to a new fictional scenario.

A 20-minute mapping session

Minutes 0–4: Choose four mixed fictional practice items. Hide the answer rationales. For each item, record only the command and the single most decision-relevant cue.

Minutes 5–10: Add the source or content domain and a one-sentence minimum rule. If you cannot state the rule without repeating the answer choices, pause and consult a current official source or your authorized training materials.

Minutes 11–15: Mark every answer choice supported, contradicted, or unsupported. Name the strongest distractor mechanism. Keep the explanation tied to the prompt rather than claiming that an option is universally wrong.

Minutes 16–20: Write one fresh fictional transfer item that uses the same rule with different surface details. Change the numbers, setting, wording, or order of information while preserving the decision boundary. Then explain what additional fact would make a different option defensible.

Track the process, not only the score: Was the command mapped correctly? Was the key cue found? Were units preserved? Did the conclusion stay within the evidence? Was the role boundary noticed? These observations show which reading step to practice next without pretending that a short session predicts an examination outcome.
