Suggested analyses

  • Error-family count: tally the signal family for each missed or uncertain practice item.
  • Near-neighbour comparison: write two plausible options, then change only the controlling sequence word.
  • Assumption audit: list every fact an answer requires that the stem never supplies.
  • Revision check: remove accidental ambiguity so the intended learning objective—not a wording trick—drives the distinction.
