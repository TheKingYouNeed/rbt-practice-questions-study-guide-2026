# Official references

Use first-party BACB sources for certification requirements and examination
policies:

- [Registered Behavior Technician information](https://www.bacb.com/rbt/?topic=rbt)
- [RBT Test Content Outline, third edition](https://www.bacb.com/wp-content/rbt-outline-3rdEd/)

Third-party study tools can provide practice and review structure, but they do
not replace official requirements. Check the BACB website for the latest
version before relying on a date, eligibility rule, or policy.
